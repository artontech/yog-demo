# YOG · 共生体网络

用 three.js 做的一个前端演示：把一张「受控节点 + 点对点 / 客户端-服务器连接」的智能体网络，画成一只不可名状的、湿滑的克苏鲁式活物。

> 纯前端效果演示。所有数据都来自浏览器里的一个小仿真器（`src/sim/Simulation.js`），不连接任何后端，也没有真正的智能体在运行。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/，相对路径，可直接丢到任意静态托管
npm run preview  # 本地预览构建产物
```

需要支持 WebGL2 的浏览器（近几年的 Chrome / Edge / Firefox / Safari，含 iOS 15+ 与 Android）。

## 画面语言

| 画面 | 含义 |
| --- | --- |
| 多结节的湿滑肉瘤 | 受控节点：一台运行着智能体的计算机 |
| 肉瘤一起一伏地「呼吸」，血管泛青光 | 该节点的智能体正在运行；静止 = 休眠 |
| 布满孔穴的高大巢丘 | 公网中继服务器（大部分节点都能直连它） |
| 暗红色、带血管的心脏 | 控制核心。选举时全网抽搐泛红，随后心脏沉入宿主，化作红色鼓包沿管道游到新当选的节点再长出来；无路可走时旧心脏枯萎、新心脏就地凝结 |
| 两端粗、中间细的对称肌腱（青色菱形纹） | 点对点连接，双向 |
| 从客户端伸出、越来越细、尖端吸在服务器上的触手（紫色人字纹朝服务器蠕动） | 客户端 → 服务器连接，方向 = 纹路流向 |
| 管道粗细 | 可用带宽（对数映射，随波动实时变粗变细） |
| 沿管道扫过、再扫过整个节点的青色光 | 可用性探测脉冲：每隔几秒从控制核心出发，洪泛到全网；到不了的节点会被标成「不可达」 |
| 管道里移动的黄绿色鼓包 | 正在传输的数据（带宽越大跑得越快；请求小、回包大） |
| 管道发灰、长斑、发抖、变细 | 连接劣化（丢包 / 抖动） |
| 管道从中间扯断，两截残肢垂落蠕动，断口泛橙光 | 连接中断；过一会儿两端会重新长到一起 |
| 两根触须各自伸出、在中间相接 | 新的点对点连接正在打洞（也可能失败缩回） |
| 卡在断口上的橙色几何晶格 | GFW 拦截了这条到公网中继的直连；流量会改走点对点中继 |
| 肉瘤干瘪发灰，连接全部缩回 | 节点掉线；恢复后重新伸出触须 |
| 地面上蔓延的黏液、脓疱和叶脉 | 菌毯：沿着连接慢慢爬过去，断开后慢慢干涸；脉冲经过会留下余辉，核心周围浸着血色 |

## 操作

- 拖动旋转、滚轮 / 双指缩放；松手几秒后自动巡游。
- 点节点或管道查看详情（带宽 / 延迟 / 丢包 / 智能体任务）；鼠标悬停管道显示带宽。
- 右下角（手机上是底部横条）的按钮可以手动触发：探测脉冲、发起选举、数据洪流、扯断连接、GFW 封锁、节点掉线（再点一次让它回来）。
- `?quality=low` / `?quality=high` 强制画质档位。默认按设备自动选择，帧率持续偏低时还会自动降低渲染分辨率。

## 改拓扑

节点和候选连接都在 `src/config.js`：

- `NODES`：`kind` 为 `server`（公网中继）或 `agent`；`region: 'cn'` 的节点到中继的直连会被 GFW 事件拦截。
- `LINKS`：`kind` 为 `cs`（`a` 是客户端、`b` 是服务器）或 `p2p`；`bw` 是标称带宽（Mbps），`lift > 0` 表示这条管道悬空拉丝而不是贴地生长，`up` 表示开场是否已连通。
- `CORE_HOST`：开场时控制核心所在的节点。

要接真实数据，只需要让一个对象提供与 `Simulation` 相同的字段（`nodes` / `links` / `pulses` / `transfers` / `core`），渲染层每帧只读这些状态。

## 目录

```
src/
  config.js          拓扑、调色板、画质档位
  main.js            启动与主循环
  sim/Simulation.js  活体网络仿真：带宽波动、断连重生、打洞、GFW、选举迁移、探测、传输
  gfx/
    Stage.js         渲染器、相机与触控、灯光、反射环境、后期（辉光 / 暗角 / 颗粒）
    World.js         把仿真状态装配成场景，提供点选
    NodeBlob.js      节点肉瘤（呼吸、吞咽、萎缩、脉冲扫过）
    Sinew.js         粘性管道（粗细、方向纹、鼓包、脉冲、断裂与重生）
    Heart.js         控制核心
    Mat.js           菌毯（2D 目标场 + GPU 乒乓缓冲做生长 / 干涸）
    Barrier.js       GFW 晶格
    Tentacles.js     节点触须与远景巨型触手
    Atmosphere.js    天穹与孢子
    glsl.js          共用噪声、法线扰动、PBR 材质注入工具
  ui/Hud.js          标签、日志、图例、按钮、详情
```
