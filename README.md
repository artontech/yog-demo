# YOG · 共生体网络

用 three.js 做的一个前端演示：把一张「受控节点 + 点对点 / 客户端-服务器连接」的智能体网络，画成一团黑亮的共生体胶质——节点是胶质球，连接是球与球之间拉出来的弹性黑丝，整张网像果冻一样会颤。

> 纯前端效果演示。所有数据都来自浏览器里的一个小仿真器（`src/sim/Simulation.js`），不连接任何后端，也没有真正的智能体在运行。

## 运行

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 产物在 dist/，相对路径，可直接丢到任意静态托管
npm run preview  # 本地预览构建产物
```

需要支持 WebGL2 的浏览器（近几年的 Chrome / Edge / Firefox / Safari，含 iOS 15+ 与 Android）。

## 画面语言

| 画面 | 含义 |
| --- | --- |
| 光滑的黑色胶质球 | 受控节点：一台运行着智能体的计算机 |
| 球一鼓一缩地「呼吸」，轮廓泛青 | 该节点的智能体正在运行；静止 = 休眠 |
| 更高、带紫色光槽的球 | 公网中继服务器（大部分节点都能直连它） |
| 暗红色的心形胶质，随心跳收缩发光 | 控制核心。选举时全网一颤、轮廓闪红，随后核心沉入宿主，化作红色鼓包沿连接游到新当选的节点再冒出来；无路可走时旧核心消散、新核心就地凝结 |
| 青色轮廓的光滑黑丝 | 点对点连接，双向 |
| 紫色轮廓、表面有流动人字纹的黑丝 | 客户端 → 服务器连接，人字纹流向服务器 |
| 丝的粗细 | 可用带宽（对数映射，1 Mbps 细如发丝，1 Gbps 粗如手臂；随波动实时变化） |
| 沿丝扫过、再扫过整个球的青色光 | 可用性探测脉冲：每隔几秒从控制核心出发，洪泛到全网；到不了的节点会被标成「不可达」 |
| 丝里移动的鼓包 | 正在传输的数据（带宽越大跑得越快；请求小、回包大）；鼓包撞进球里会把球推得一晃 |
| 丝失去光泽、发灰、发抖、变细 | 连接劣化（丢包 / 抖动） |
| 丝从中间扯断，断口拉出几根粘丝后崩开，两端弹回成尖 | 连接中断；过一会儿两端重新伸出，先搭上粘丝再长回一根 |
| 两根细丝各自伸出、在中间相接 | 新的点对点连接正在打洞（也可能失败缩回） |
| 卡在断口上的橙色几何晶格 | GFW 拦截了这条到公网中继的直连；流量会改走点对点中继 |
| 球塌成一滩、失去光泽，连接全部缩回 | 节点掉线；恢复后重新鼓起、伸出细丝 |
| 地面上那层边缘圆润的黑色胶质 | 菌毯：沿着连接慢慢漫过去，断开后慢慢退走；连接越粗身下越宽；脉冲经过会留下余辉 |

## 操作

- 拖动旋转、滚轮 / 双指缩放；松手几秒后自动巡游。
- 点节点或连接查看详情（带宽 / 延迟 / 丢包 / 智能体任务）；鼠标悬停连接显示带宽。
- 右下角（手机上是底部横条）的按钮可以手动触发：探测脉冲、发起选举、数据洪流、扯断连接、GFW 封锁、节点掉线（再点一次让它回来）。
- `?quality=low` / `?quality=high` 强制画质档位。默认按设备自动选择，帧率持续偏低时还会自动降低渲染分辨率。

## 改拓扑

节点和候选连接都在 `src/config.js`：

- `NODES`：`kind` 为 `server`（公网中继）或 `agent`；`region: 'cn'` 的节点到中继的直连会被 GFW 事件拦截。
- `LINKS`：`kind` 为 `cs`（`a` 是客户端、`b` 是服务器）或 `p2p`；`bw` 是标称带宽（Mbps），`lift > 0` 表示这根丝从别的连接上方拱过去，`up` 表示开场是否已连通。
- `CORE_HOST`：开场时控制核心所在的节点。
- 带宽到粗细的映射在 `src/gfx/Sinew.js` 的 `radiusForBandwidth`。

要接真实数据，只需要让一个对象提供与 `Simulation` 相同的字段（`nodes` / `links` / `pulses` / `transfers` / `core`）和 `kick` 事件，渲染层每帧只读这些状态。

## 目录

```
src/
  config.js          拓扑、调色板、画质档位
  main.js            启动与主循环
  sim/Simulation.js  活体网络仿真：带宽波动、断连重连、打洞、GFW、选举迁移、探测、传输
  gfx/
    Stage.js         渲染器、相机与触控、灯光、反射环境、后期（辉光 / 暗角 / 颗粒）
    World.js         把仿真状态装配成场景；果冻晃动的弹簧物理；点选
    NodeBlob.js      节点胶质球（呼吸、吞咽、塌陷、晃动、脉冲扫过）
    Sinew.js         连接（粗细、方向纹、鼓包、脉冲、扯断时的粘丝与重连）
    Heart.js         控制核心
    Mat.js           地面胶质（2D 目标场 + GPU 乒乓缓冲做漫延 / 退走）
    Barrier.js       GFW 晶格
    Atmosphere.js    天穹与浮尘
    glsl.js          共用噪声、法线扰动、PBR 材质注入工具
  ui/Hud.js          标签、日志、图例、按钮、详情
```
